利用規約

最終更新日: 2026年6月4日

本利用規約（以下「本規約」）は、chom（以下「開発者」）が提供する iOS アプリ「MasterGate」（以下「本アプリ」）の利用条件を定めます。ユーザーは本アプリを利用することにより、本規約に同意したものとみなされます。

1. 提供サービス

本アプリは、ユーザーが自ら選んだアプリへのアクセスを学習クイズ完了時のみ許可するセルフコントロール／学習ツールです。具体的には以下の機能を提供します：

  • iOS の FamilyControls / ManagedSettings / DeviceActivity API を利用したアプリブロック
  • 内蔵プリセット・自作カード・AI生成による学習クイズ
  • クイズ完了による利用枠の獲得と消費管理

2. 利用環境

  • iOS 17.0 以降を搭載した iPhone
  • FamilyControls の認可（本アプリの動作に必須）
  • AI機能および購入機能の利用にはインターネット接続が必要

3. 課金とサブスクリプション

3.1 プレミアム機能

本アプリは「フリーミアム」モデルで提供されます。基本機能（10ジャンルのプリセット学習、クイズによるアプリブロック解除、自作カード追加、統計表示等）はすべて無料で利用可能です。

以下の機能は無料枠の制限内で利用可能で、超過時はプレミアム会員のみが継続利用できます：

  • AI による問題自動生成：無料枠は累計10問まで
  • 写真からの取込（AI後処理あり）：無料枠は毎月10回まで
  • その他、追加プレミアム機能（カスタムテーマ、広告非表示、詳細統計等）

料金は本アプリ内およびApp Storeに表示されます。

3.2 自動更新サブスクリプション

  • プレミアムは自動更新サブスクリプションで提供されます
  • 期間終了の24時間以上前に解約しない限り、自動的に更新されます
  • 解約は iOS の「設定 → Apple ID → サブスクリプション」から行えます
  • 既に経過した期間分の返金は原則として行いません

3.3 無料トライアル

  • 初回購入時に7日間の無料トライアルが付与されます
  • トライアル期間終了の24時間以上前に解約しない限り、選択したプランで自動課金が開始されます
  • 同一 Apple ID では、プラン区別なくトライアル特典は一度のみ利用可能です

3.4 価格

  • 月額プラン: ¥480 / 月
  • 年額プラン: ¥2,980 / 年（実質 ¥249/月、月額換算で約48% お得）

価格は App Store の表示に従います。為替や税制の変更により改定される場合があります。
